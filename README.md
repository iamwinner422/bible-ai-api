# AI-Powered Bible Search

Semantic search API for the Louis Segond 1910 (LSG) Bible. It converts passages into embeddings with FastEmbed, then ranks results by their similarity to the query.

## Prerequisites

- Python 3.10 or later
- An Internet connection on first run to download the embedding model

## Installation

From the project root, create and activate a virtual environment, then install the dependencies:

```cmd
python -m venv env
.\env\Scripts\activate.bat
python -m pip install -r requirements.txt
```

## Build the index

The default source file is `data/bible_fr.json`. Generate the index files before starting the API:

```cmd
python build_index.py
```

The script creates:

- `outputs/bible_emb.npy`: passage embeddings
- `outputs/bible_meta.json`: the corresponding texts and references

Each passage contains up to three verses. Index generation may take a while; the model is downloaded to `models` the first time it is used.

## Run the API

From the project root:

```cmd
uvicorn main:app --reload
```

The API is then available at `http://127.0.0.1:8000`. Interactive documentation is available at [`/docs`](http://127.0.0.1:8000/docs).

## Usage

### Check the API health

```cmd
curl http://127.0.0.1:8000/
```

The response contains the status (`ok`) and the number of indexed passages.

### Search for a passage

The `query` parameter contains the question or keywords. `responseSize` is optional, defaults to 8, and is limited to a range of 1 to 20.

```cmd
curl "http://127.0.0.1:8000/search?query=love%20and%20forgiveness&responseSize=5"
```

Each result includes a Bible reference, the passage text, the semantic similarity score, and whether keyword matching contributed:

```json
[
  {
    "reference": "Jean 3:16 (LSG)",
    "text": "Car Dieu a tant aimé le monde...",
    "score": 0.72,
    "mots_cles": true
  }
]
```

Each result contains one verse only. Results can match the query semantically or lexically; `mots_cles` indicates whether a query word also appears in the verse. To apply this change to an existing installation, rebuild the index with `python build_index.py` and restart the API.
